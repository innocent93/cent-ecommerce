# Enterprise Roadmap

## High-value improvements after this release

1. **Audit log:** immutable records for seller approval, bans, refunds, payouts, coupon changes and staff actions.
2. **Fine-grained RBAC:** move from broad admin permissions to resource/action policies.
3. **MFA for staff:** WebAuthn/TOTP for privileged accounts.
4. **Payout controls:** maker/checker approval for high-value seller payouts.
5. **Fraud controls:** velocity rules, device/IP risk scoring and suspicious-order review.
6. **Inventory reservations:** transactional reservation with expiry for high-demand products.
7. **Observability:** distributed tracing, metrics, structured logs and alerting.
8. **Search:** dedicated search engine when MongoDB text search no longer meets latency/relevance targets.
9. **Image pipeline:** responsive image variants, WebP/AVIF, CDN caching and moderation.
10. **Customer trust:** seller ratings, verified purchase reviews, return reason analytics and dispute workflows.
11. **Accessibility:** WCAG-focused audit for keyboard navigation, contrast, labels and screen readers.
12. **Release engineering:** CI/CD, dependency scanning, secret scanning, migration gates and automated rollback.
13. **Data governance:** retention policies, export/delete requests and privacy controls.
14. **Business intelligence:** cohort retention, seller GMV, take rate, conversion funnel, refund rate and contribution margin.
