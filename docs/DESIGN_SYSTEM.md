# UrbanStep Design System

## Reference direction

The visual language follows the approved UrbanStep reference board and borrows useful interaction patterns from high-quality commerce/admin work such as Dribbble's ecommerce dashboard references. The goal is not to copy any third-party design; it is to extract proven patterns: clear hierarchy, compact data density, strong navigation, purposeful cards and obvious primary actions. citeturn0search0turn0search1turn0search5

## Principles

- Fashion-first, not generic marketplace UI.
- White/soft-gray surfaces with UrbanStep blue as the action color.
- Large editorial imagery balanced with compact commerce controls.
- One primary action per surface.
- Consistent 12–16px control radii and 20–28px surface radii.
- Dense admin tables, spacious customer discovery.
- Mobile bottom navigation for the shopper app.
- Seller/admin side navigation with persistent context.
- Every screen has loading, empty, success and error states.

## Design tokens

- Primary: UrbanStep blue
- Ink: deep navy
- Surface: white
- Canvas: cool near-white
- Success: emerald
- Warning: amber
- Danger: red
- Border: cool slate

Use Tailwind tokens rather than page-specific arbitrary values wherever practical.
