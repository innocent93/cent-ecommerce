# UrbanStep design previews

These previews are client-facing direction boards for the UrbanStep marketplace.
The intended visual language is a polished blue/white fashion storefront with:

- spacious editorial hero sections;
- rounded cards and restrained shadows;
- clear primary actions;
- consistent authentication screens;
- responsive mobile-first layouts;
- a dark, data-focused admin workspace;
- a clean seller workspace with the same UrbanStep design tokens.

The images are design references, not proof of a completed production build.
